Аккаунты бирж

Чат работает с биржами, у которых есть официальный API: Freelancehunt и Freelancer.com. Токены хранятся только в базе Radar на вашем компьютере.

freelancehunt.com → Настройки → API → «Создать токен».
accounts.freelancer.com/settings/develop → создать приложение и выпустить токен с правами basic, fln:project_manage, fln:messaging.
