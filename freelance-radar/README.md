# Radar — заказы, которые можно сделать с ИИ

Сайт собирает фриланс-заказы с нескольких бирж в одну базу SQLite, оценивает каждый заказ
и показывает их в чёрно-белом интерфейсе в стиле liquid glass.

## Запуск
- **Windows:** двойной клик по `start.bat`
- **macOS / Linux:** `./start.sh`
- Вручную: `pip install -r requirements.txt && python -m radar`, затем откройте http://localhost:8000

Сервер собирает заказы сразу при старте, а потом каждые 15 минут (`RADAR_INTERVAL_MIN`).
База копится в `orders.db`, старые заказы не удаляются.

## Источники
| Биржа | Как берём | Сколько за проход |
|---|---|---|
| FL.ru | RSS (все + 6 категорий) | ~350 |
| Freelancer.com | публичный API | ~1000 |
| Pchel.net | HTML, 6 страниц | ~300 |
| Freelance.ru | HTML, 8 страниц | ~200 |
| PeoplePerHour | HTML, 5 страниц | ~100 |
| Freelancehunt | RSS | ~50 |
| Kwork | JSON | ~60, только с домашнего IP: дата-центры Kwork блокирует |

Хабр Фриланс закрылся, поэтому его нет. Новая биржа добавляется функцией в `radar/scrapers.py`
и строчкой в словаре `SOURCES`.

## Как оценивается заказ (`radar/classify.py`)
- **Бюджет в ₽.** Валюта переводится по примерным курсам из `RATES`. У почасовых заказов
  берётся ставка × 20 часов.
- **Сложность 1–5.** Эвристика по ключевым словам (маркетплейс, CRM, мобильное приложение
  дают +; лендинг, правки, логотип дают −), размеру бюджета и длине ТЗ.
- **По силам ИИ, %.** Зависит от направления: боты, скрипты, сайты и тексты дают высокий балл.
  Сильно снижается, если нужны звонки, продажи, офлайн, юрист, отзывы и т.п.
- Сортировка «Выгоднее» = бюджет × ИИ% ÷ сложность.

## Команды
- `python -m radar scrape` — один проход сбора без сайта
- `python -m radar export static/orders.json` — снимок базы. Страница сама подхватит
  `orders.json`, если сервер не запущен, поэтому её можно выложить как статический сайт.
