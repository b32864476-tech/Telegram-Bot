# Radar — заказы, которые можно сделать с ИИ

Сайт собирает фриланс-заказы с нескольких бирж в одну базу SQLite, оценивает каждый заказ
и показывает их в чёрно-белом интерфейсе в стиле liquid glass.

## Запуск
- **Windows:** двойной клик по `start.bat`
- **macOS / Linux:** `./start.sh`
- Вручную: `pip install -r requirements.txt && python -m radar`, затем откройте http://localhost:8000

Сервер собирает заказы сразу при старте, а потом каждые 15 минут (`RADAR_INTERVAL_MIN`).
База копится в `orders.db`, старые заказы не удаляются.

## С телефона
Сайт сделан под телефон: внизу панель под большой палец (поиск, фильтры, сортировка, наверх),
фильтры и карточки заказов открываются шторкой снизу и закрываются свайпом вниз или кнопкой «Назад».

**Дома, по Wi-Fi.** При запуске в консоли появится строка вида
`с телефона (та же Wi-Fi сеть): http://192.168.1.5:8000`. Откройте её на телефоне.
Если не открывается, разрешите Python в брандмауэре Windows (частные сети).

**Иконка на экране.** Safari: «Поделиться» → «На экран „Домой“». Chrome: ⋮ → «Добавить на главный экран».
Сайт откроется как отдельное приложение без адресной строки.

**Вне дома.** Компьютер с запущенным Radar должен быть включён. Задайте пароль и откройте туннель:
```bash
# Windows (PowerShell):  $env:RADAR_PASSWORD="ваш-пароль"; .\start.bat
# macOS / Linux:         RADAR_PASSWORD=ваш-пароль ./start.sh
cloudflared tunnel --url http://localhost:8000     # бесплатно, без регистрации
```
cloudflared выдаст адрес `https://….trycloudflare.com`. Откройте его с телефона и введите пароль
(логин любой). Без `RADAR_PASSWORD` сайт наружу не открывайте.

и строчкой в словаре `SOURCES`.

## Как оценивается заказ (`radar/classify.py`)
- **Бюджет в ₽.** Валюта переводится по примерным курсам из `RATES`. У почасовых заказов
  берётся ставка × 20 часов.
- **Сложность 1–5.** Эвристика по ключевым словам (маркетплейс, CRM, мобильное приложение
  дают +; лендинг, правки, логотип дают −), размеру бюджета и длине ТЗ.
- **По силам ИИ, %.** Зависит от направления: боты, скрипты, сайты и тексты дают высокий балл.
  Сильно снижается, если нужны звонки, продажи, офлайн, юрист, отзывы и т.п.
- **Сроки.** Для каждого заказа считается, сколько часов он займёт с ИИ (диапазон) и без ИИ.
  Оценка складывается из сложности и направления (тексты быстрее, приложения дольше),
  объёма из ТЗ («5 статей», «3000 слов», «10 баннеров»), лишней работы (оплата, админка,
  интеграции) и бюджета: дорогой заказ вряд ли на 15 минут. Если заказчик указал срок,
  сайт пишет: «успеваете», «впритык» или «не успеть».
- **₽ в час.** Бюджет делится на оценку часов с ИИ. У почасовых заказов это сама ставка.
- В карточке заказа есть план работы по этапам с часами на каждый.
- Сортировки «Выгоднее» (₽ в час) и «Быстрее» (меньше часов), фильтр «Сделать за».
- Коэффициенты лежат в начале блока «сроки» в `radar/classify.py`, их можно подстроить под свой темп.

## Команды
- `python -m radar scrape` — один проход сбора без сайта
- `python -m radar export static/orders.json` — снимок базы. Страница сама подхватит
  `orders.json`, если сервер не запущен, поэтому её можно выложить как статический сайт.
