# ПК Клавиатура — клавиатура и тачпад для компьютера с iPhone

iPhone превращается в полноценную клавиатуру и тачпад для компьютера (Windows, macOS, Linux)
по Wi‑Fi. Клавиши работают как настоящие: нажатие и отпускание передаются отдельно, поэтому
можно держать клавишу (автоповтор, игры), зажимать Shift/Ctrl/Alt/Win и нажимать сочетания.

## Что умеет

- **Клавиатура** — полная раскладка ПК: Esc, F1–F12, цифры, буквы (с русскими буквами на клавишах),
  Tab, Caps, Shift, Ctrl, Win/⌘, Alt, стрелки, Del, Backspace, Enter.
  - Клавиши нажимаются по **положению**, как на настоящей клавиатуре: текст печатается в той раскладке,
    что выбрана на компьютере, а Ctrl+C / Ctrl+V работают и в русской раскладке.
  - Кнопка 🌐 переключает раскладку на компьютере (Win+Space, на Mac — Ctrl+Space).
  - Модификаторы: одно касание — «залипает» на одну клавишу, двойное — закрепляется, ещё одно — отпускается.
    Можно и просто держать пальцем.
  - Вертикально сверху появляется мини‑тачпад, горизонтально — клавиатура на весь экран.
- **Текст** — печать обычной клавиатурой iPhone: любой язык, эмодзи, диктовка, автоисправление.
  Текст сразу появляется на компьютере (или режим «написать и отправить»).
- **Тачпад** — курсор одним пальцем, тап — клик, тап двумя — правый клик, два пальца — прокрутка,
  двойной тап с удержанием — перетаскивание, отдельные кнопки мыши и полоса прокрутки.
- **Ещё** — копировать/вставить/отменить, переключение окон, скриншот, диспетчер задач,
  вкладки браузера, громкость и музыка, Home/End/PgUp/PgDn и т. д. Сочетания подстраиваются под ОС.

## Установка на Mac

1. **Python.** Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/macos/)
   (кнопка «Download Python 3.x») и установите как обычную программу.
2. **Скачайте проект** на Mac: откройте
   [архив ветки](https://github.com/b32864476-tech/Telegram-Bot/archive/refs/heads/claude/exciting-lovelace-j1oloo.zip)
   (нужно быть залогиненным в GitHub), распакуйте — внутри будет папка `phone-keyboard`.
3. **Запустите `start.command`** двойным кликом. Если macOS пишет «не удаётся проверить разработчика» —
   нажмите на файл правой кнопкой → «Открыть» → «Открыть».
   Можно и через Терминал: перетащите папку `phone-keyboard` в окно Терминала после `cd `,
   нажмите Enter и выполните `bash start.sh`.
   Первый запуск ставит зависимости (1–2 минуты), потом в окне Терминала появится QR‑код.
4. **Разрешите управление.** macOS откроет окно «Универсальный доступ»:
   «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ» →
   включите **Терминал** (если его нет — «+» → Программы → Утилиты → Терминал;
   если запускаете из iTerm или другой программы — включите её).
   После этого **закройте окно Терминала и запустите `start.command` ещё раз.**
   Без этого разрешения macOS молча игнорирует нажатия.
5. Если macOS спросит «Разрешить входящие подключения для Python?» — нажмите **«Разрешить»**.
6. iPhone и Mac должны быть **в одной сети Wi‑Fi**. Наведите камеру iPhone на QR‑код,
   откроется Safari. Нажмите **«Поделиться» → «На экран Домой»** — появится иконка «Клавиатура».

### Особенности Mac

- Нижний ряд как на клавиатуре Mac: **control · option · command · пробел · command · option**.
  Сочетания во вкладке «Ещё» уже маковские: ⌘C/⌘V, Spotlight, Mission Control, ⌘Tab,
  скриншоты ⌘⇧4/⌘⇧5, блокировка экрана, принудительное завершение и т. д.
- **Смена раскладки 🌐** по умолчанию нажимает **⌃ Control + Space** («Выбрать предыдущий источник ввода»).
  Если у вас раскладка переключается иначе — выберите своё сочетание в настройках приложения (⚙).
  Проверить сочетание на Mac: «Системные настройки → Клавиатура → Сочетания клавиш → Источники ввода».
  Переключение клавишей Globe/Fn или Caps Lock эмулировать нельзя — включите там сочетание ⌃ Space.
- Вкладка «Текст» печатает символы как Юникод — русский/английский текст и эмодзи выходят правильно
  при любой раскладке, выбранной на Mac.
- **Caps Lock** работает (включается как с настоящей клавиатуры), автоповтор при удержании клавиши — тоже.
- Двойной тап по тачпаду — настоящий двойной клик, прокрутка двумя пальцами плавная, как на трекпаде.
  ⌘+клик и ⇧+клик работают (зажмите ⌘ на вкладке «Клавиатура» и тапните по мини‑тачпаду).
  Если прокрутка идёт «не в ту сторону» — переключите «Естественная прокрутка» в настройках приложения.
- **Экран блокировки.** Ввести пароль от Mac с телефона нельзя: на экране блокировки macOS принимает
  только настоящую клавиатуру (защита от подбора пароля программами). Приложение это видит и показывает
  «🔒 Mac заблокирован» — разблокируйте Mac через Touch ID, Apple Watch или его клавиатуру.
  Для разблокировки с iPhone подойдёт встроенный «Общий экран» (VNC) macOS и VNC‑клиент на телефоне.
- Пока программа запущена, Mac не уходит в сон сам (экран при этом может гаснуть — нажатие с телефона
  его разбудит). Если закрыть крышку MacBook без внешнего монитора, Mac уснёт и связь пропадёт.

## Windows / Linux

- **Windows:** установите Python с python.org (отметьте «Add python.exe to PATH») и запустите `start.bat`.
  Брандмауэр спросит про доступ к сети — разрешите для частных сетей. Ctrl+Alt+Del и Win+L Windows
  эмулировать не даёт.
- **Linux:** `./start.sh`, работает в сеансе X11 (в Wayland ввод от программ обычно заблокирован).

## Параметры

```
./start.sh --port 9000     # другой порт (по умолчанию 8765)
./start.sh --new-key       # новый ключ доступа (старые ссылки перестанут работать)
./start.sh --dry-run       # ничего не нажимать, только печатать события (для проверки)
```

## Безопасность

- Подключиться может только тот, у кого есть ссылка с ключом (`?k=...`). Ключ хранится
  в `~/.phone_keyboard_token` и не меняется между запусками, поэтому ярлык на iPhone продолжает работать.
- Если ссылка попала к чужому — запустите с `--new-key` и заново добавьте ярлык.
- Используйте только в домашней/доверенной сети: трафик внутри Wi‑Fi не шифруется.
- При обрыве связи все зажатые клавиши и кнопки мыши автоматически отпускаются.

## Если не подключается

- Проверьте, что окно программы открыто и телефон в той же сети (не в гостевой и не через мобильный интернет).
- На Mac: «Системные настройки → Сеть → Файрвол» — Python должен быть разрешён.
- Связь есть, но ничего не нажимается — не выдано разрешение «Универсальный доступ» (см. шаг 4).
- Если у компьютера сменился IP‑адрес — снова отсканируйте QR‑код и пересоздайте ярлык.
- На роутере может быть включена «изоляция клиентов» (AP isolation) — её нужно выключить.

## Почему не приложение из App Store

iOS не позволяет приложениям притворяться Bluetooth‑клавиатурой, а установка своего нативного
приложения требует Mac с Xcode и переподписи каждые 7 дней. Веб‑приложение на экране «Домой»
работает на любом iPhone (iOS 16+) без этого и выглядит как обычное приложение.
