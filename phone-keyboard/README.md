# ПК Клавиатура — клавиатура и тачпад для компьютера с iPhone

iPhone превращается в полноценную клавиатуру и тачпад для компьютера (Windows, macOS, Linux)
по Wi‑Fi. Клавиши работают как настоящие: нажатие и отпускание передаются отдельно, поэтому
можно держать клавишу (автоповтор, игры), зажимать Shift/Ctrl/Alt/Win и нажимать сочетания.

## Что умеет

- **Клавиатура** — полная раскладка ПК: Esc, F1–F12, цифры, буквы (с русскими буквами на клавишах),
  Tab, Caps, Shift, Ctrl, Win/⌘, Alt, стрелки, Del, Backspace, Enter.
  - Клавиши нажимаются по **положению**, как на настоящей клавиатуре: текст печатается в той раскладке,
    что выбрана на компьютере, а Ctrl+C / Ctrl+V работают и в русской раскладке.
  - Кнопка 🌐 переключает раскладку на компьютере (Win+Space, на Mac — Ctrl+Space).
  - Модификаторы: одно касание — «залипает» на одну клавишу, двойное — закрепляется, ещё одно — отпускается.
    Можно и просто держать пальцем.
  - Вертикально сверху появляется мини‑тачпад, горизонтально — клавиатура на весь экран.
- **Текст** — печать обычной клавиатурой iPhone: любой язык, эмодзи, диктовка, автоисправление.
  Текст сразу появляется на компьютере (или режим «написать и отправить»).
- **Тачпад** — курсор одним пальцем, тап — клик, тап двумя — правый клик, два пальца — прокрутка,
  двойной тап с удержанием — перетаскивание, отдельные кнопки мыши и полоса прокрутки.
- **Ещё** — копировать/вставить/отменить, переключение окон, скриншот, диспетчер задач,
  вкладки браузера, громкость и музыка, Home/End/PgUp/PgDn и т. д. Сочетания подстраиваются под ОС.

## Установка

Нужен **Python 3.9+** на компьютере ([python.org](https://www.python.org/downloads/),
на Windows при установке отметьте «Add python.exe to PATH»).

1. Скачайте папку `phone-keyboard` на компьютер.
2. Запустите:
   - **Windows:** двойной клик по `start.bat`
   - **macOS / Linux:** `./start.sh` в терминале

   При первом запуске установятся зависимости. В окне появятся адрес и QR‑код.
3. iPhone и компьютер должны быть **в одной сети Wi‑Fi**. Наведите камеру iPhone на QR‑код
   (или введите адрес в Safari).
4. В Safari нажмите **«Поделиться» → «На экран Домой»**. Появится иконка «Клавиатура»,
   которая открывается на весь экран как обычное приложение.

### Первый запуск на разных системах

- **Windows:** брандмауэр спросит про доступ к сети — разрешите для **частных сетей**.
  Клавиатура не работает в окнах, запущенных «от имени администратора», если сама программа
  запущена без прав администратора (ограничение Windows). Ctrl+Alt+Del и Win+L Windows эмулировать не даёт.
- **macOS:** «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ»
  (и «Мониторинг ввода») — включите для Терминала / Python.
- **Linux:** работает в сеансе X11. В Wayland ввод от программ обычно заблокирован.

## Параметры

```
start.bat --port 9000     # другой порт (по умолчанию 8765)
start.bat --new-key       # новый ключ доступа (старые ссылки перестанут работать)
start.bat --dry-run       # ничего не нажимать, только печатать события (для проверки)
```

## Безопасность

- Подключиться может только тот, у кого есть ссылка с ключом (`?k=...`). Ключ хранится
  в `~/.phone_keyboard_token` и не меняется между запусками, поэтому ярлык на iPhone продолжает работать.
- Если ссылка попала к чужому — запустите с `--new-key` и заново добавьте ярлык.
- Используйте только в домашней/доверенной сети: трафик внутри Wi‑Fi не шифруется.
- При обрыве связи все зажатые клавиши и кнопки мыши автоматически отпускаются.

## Если не подключается

- Проверьте, что окно программы открыто и телефон в той же сети (не в гостевой и не через мобильный интернет).
- Если у компьютера сменился IP‑адрес — снова отсканируйте QR‑код и пересоздайте ярлык.
- На роутере может быть включена «изоляция клиентов» (AP isolation) — её нужно выключить.

## Почему не приложение из App Store

iOS не позволяет приложениям притворяться Bluetooth‑клавиатурой, а установка своего нативного
приложения требует Mac с Xcode и переподписи каждые 7 дней. Веб‑приложение на экране «Домой»
работает на любом iPhone (iOS 16+) без этого и выглядит как обычное приложение.
